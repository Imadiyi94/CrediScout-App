# ADR 0003 — Cloudflare R2 behind an S3-compatible client (Adobe S3Mock locally)

Date: 2026-09-28 · Status: accepted

## Context
Documents must be stored server-side now (local machine) and in Cloudflare later,
with zero code changes at migration.

## Decision
All storage goes through the AWS S3 SDK with `forcePathStyle`. `STORAGE=r2` selects
Cloudflare R2 (`R2_*` vars); otherwise the local endpoint is used. Local stand-in is
Adobe S3Mock (port 9090, bucket auto-created) — chosen after MinIO left Docker Hub
and LocalStack gated `latest` behind a license token.

## Consequences
+ One code path; cutover = env vars + pre-created R2 bucket.
+ Downloads stream through an ownership-checked app route (no public URLs).
− Presigned-URL flows must be re-verified against R2 at cutover (see runbook).
